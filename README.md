Hey, this is my Game Dashboard project.It's a front-end app where you can manage your top 3 video games, save favorites, and track how long you actually play them.I also built a custom login and signup screen that blocks the main page until you put in your details.It uses your browser's localStorage, so whatever games you change or hours you log stay saved when you refresh or close the page.What it doesAutomatic Session you just click "Start Playing". It logs your exact start time using your computer's clock. When you hit "Stop Playing", it calculates exactly how many hours passed down to the millisecond and updates the card.Account Login System:The dashboard content stays completely hidden when you first open the page. You have to create a quick local account and log in to make the white box vanish and show the dashboard.Top 3 Customizer:You can hit the edit button to rename any of the three game cards to whatever you want, and it updates the display instantly.Favorites Toggle:You can click the star on any card to favorite it, and it stays starred even after reloading.File LayoutEverything sits right next to each other inside one folder:index.html — The basic webpage layout for the login forms, game cards, and settings inputs.style.css — The colors, grid sizing, and custom dark mode theme looks.script.js — The logic running the timers, matching passwords, and saving arrays to memory.How to run and test itMake sure index.html, style.css, and script.js are all sitting in the exact same folder on your computer.Double-click index.html to open it up in Google Chrome or whatever browser you use.The dashboard will be invisible. Go to the "Create Account" section first, make a test email/password, and sign up.Use those exact details in the "Log In" box. The window will close out and open the dashboard features.Testing the timer: Click "Start Playing" on one of the cards. Make sure you leave it running for at least 40 seconds before hitting stop. Because the page calculates playtime in decimal hours (like 0.01 hours), anything under 40 seconds will round down to 0.00 and look like it didn't work. Letting it run for 40+ seconds will cleanly pass the rounding threshold and update the card text!
